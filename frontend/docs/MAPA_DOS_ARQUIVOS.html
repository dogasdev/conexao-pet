Conexão com o backend

Navegador → frontend → API Java → MySQL

Login: /api/auth/login · anúncios: /api/anuncios
Cadastro: /api/auth/cadastro/usuario ou /instituicao

O frontend não recebe a senha do MySQL nem a chave JWT_SECRET. A API Java verifica o dono do anúncio nas alterações.
