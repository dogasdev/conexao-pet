# Conexão Pet

Frontend React/Vite: página principal, login, cadastro e páginas legais.

Consulte [o guia completo](docs/LEIA_PRIMEIRO.md) e abra docs/MAPA_DOS_ARQUIVOS.html para ver a organização.

```sh
npm ci
npm run dev
```

Validação: `npm test` e `npm run build`. API de login/cadastro integrada ao contrato Java; vitrine, ficha e gestão de anúncios integradas à API Java.
