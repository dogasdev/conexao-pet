# CONEXÃO PET! 🐾
Plataforma web para divulgação de animais disponíveis para adoção.

## Sobre o projeto
O CONEXÃO PET é um projeto acadêmico que tem como objetivo proporcionar um ambiente flexível para a divulgações de animais em adoção, conectando pessoas e instituições que disponibilizam animais para adoção. 

A plataforma permitirá cadastrar animais, consultar informações e pesquisar animais disponível para adoção

### Tecnologias
Backend : Java + Spring Boot
Frontent : HTML + CSS + JavaScript + React
Banco de Dados : MySQL
